## 실행 조건

첫 스키마 생성은 식별이 맞는 빈 전용 DB만, 이후 validate. 기본 qwen3:4b-instruct Q4_K_M, temperature=0, seed=42, context8192, output1024. CPU 먼저, 필요시 공식 서명 확인한 macOS Ollama. 대안 qwen2.5:7b-instruct-q4_K_M. 신규 다운로드 합계10GB 이내. 모델 요청240초, 대기900초, 동시1. 기존 OpenClaw 보존. 농약 명칭과 기존 총살포량 프롬프트 표현은 변경하지 않는다. 새로운 농약 사용 적합성 판정은 구현하지 않는다.

공식 출처라도 작물/품종/조건/날짜를 대조하고 의약 효능/민간요법/광고는 제외한다. 534개 카탈로그 구조 점검은 전체 품질 검증이 아니다. 문헌 일치는 농장 효과 검증이 아니다. 전체 자유 메모/농업 조합 전수 검증을 주장하지 않는다.

진행·재개·실제 명령/결과는 Git 제외 .local/rag-api/{progress,continuation}.md와 결과 문서에 기록한다. 비밀번호·JWT는 로그/커밋에 넣지 않는다. 필요시 Chrome/카카오톡/Notion만 정상 종료하고 미저장 창은 건너뛰며 이유를 기록한다. Docker/시스템/Codex 설정과 프로세스는 변경/강제 종료하지 않는다.

## 검토 초점

잘못된 DB의 초기화, 초기화 실패 후 재생성, 자격 증명/로그 노출, 공유 모델 볼륨 동시 쓰기, 실제 외부 제공자 호출, 평가 오염, stale 응답·수정/재생성 경합, 잘못된 작물/농약 근거의 단정.
